# FitKoçum 3D

Türkçe, çevrimdışı çalışan Android fitness uygulaması. 18 egzersiz, 3D karikatür egzersiz animasyonları, üç günlük antrenman programı, set ve kilo kaydı.

**APK indir:** GitHub > Actions > FitKoçum 3D APK > başarılı çalışma > Artifacts > FitKocum-3D-APK.

Kaynak kodu GitHub Actions ile Android debug APK olarak derlenir. 3D animasyonlar basitleştirilmiş görsel anlatımlardır; birebir anatomik hareket yakalama değildir.
